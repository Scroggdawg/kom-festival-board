# KILLER OF MEN press kit in Canva — runbook

*Written 2026-09-10 so that any account, on any machine, can execute this build from cold or resume one that another account started. Read `STATE.json` first: it says what has been done and what is next. Update it in the same turn a step completes.*

## What this is

The eleven-page festival press kit (EPK) for KILLER OF MEN exists as a PDF with live text and links, as an Illustrator project, and as one Python layout (`tools/build-epk-kit.py`). This folder rebuilds the same kit inside Canva so the director and producer can edit it there. Once built and accepted, **Canva is the master** for the kit's words (Luke, 2026-09-10); the worksheet and the PDF/.ai remain the source only for what they already produce.

The mechanism is a small Canva app (`kom-epk-builder/`) that the account owner runs inside the Canva editor. It reads a JSON operation list produced from the layout (`ops/epk-canva.json`) and places every page, image, text run, rule and link. Nothing is typed into Canva by hand except where this runbook says so.

The plan and its research: `press/canva-plan.md`.

## Steps

Each step ends with a check. Record the result in `STATE.json` before moving on.

### 1. Regenerate the operations (repo, no Canva needed)

```bash
venv/bin/python tools/build-epk-canva.py
```

Check: it prints `11 pages, N elements, 22 images, 20 links attached, 0 unattached`, and `press/assets/derived/canva/` holds 22 JPEGs. If links are unattached it exits non-zero; fix the layout, not the JSON. Commit `canva/ops/epk-canva.json` and the derived images by explicit path and push, then wait about a minute and confirm `curl -sI https://scroggdawg.github.io/kom-festival-board/canva/ops/epk-canva.json` returns 200. The app cannot see uncommitted files.

### 2. Run the app locally

```bash
cd canva/kom-epk-builder && npm install && npm start
```

Check: the dev server answers on http://localhost:8080. Leave it running while the editor is open.

### 3. Create the app in the Developer Portal (once per Canva account)

Luke, or an agent in his Chrome with his OK: https://www.canva.dev/ › Your apps › Create an app › name `kom-epk-builder` › App source › Development URL `http://localhost:8080` › Preview. Accepting the Developer Terms is Luke's own click. Record the app id in `STATE.json`.

Check: the Preview button opens a Canva editor with the app's panel on the left.

### 4. Probes (about 30 minutes, decide the fidelity budget)

| Probe | How | Record in STATE |
|---|---|---|
| PDF import | Drag `press/KillerOfMen_EPK_<latest>.pdf` onto the Canva home page; open the result | page count, page size, which pages have editable text, substituted font, surviving links (expect 0). Keep or delete the design; it is a comparison, not the build |
| Fonts | In the app panel: "Find Libre Baskerville" and, for each font key, "Pick font" | the FontRef, name and weights per key; whether an uploaded Baskerville appeared (expect no) |
| Page size | Open a design from the 18 × 24 in poster preset (Create a design › Poster › Custom size 18 × 24 in) with the app open; press "Probe: page size" | width and height in px; the scale `s` = width / 1296 |

If the Preview button will only open a fresh design and the app cannot be opened inside the poster, use the app's build with explicit dimensions in the fresh design and delete its default page.

### 5. Pilot: page 3 only

In the app: Load operations (the default URL), then Build page 3. Export the design as PDF Standard with Flatten OFF (Share › Download › PDF Standard).

Check with the venv:

```bash
venv/bin/python - <<'EOF'
import pymupdf, sys
d = pymupdf.open("/path/to/downloaded.pdf")
p = d[0]; print(p.rect, len(p.get_text()), "chars", len(p.get_links()), "links")
print(sorted({l.get("uri") for l in p.get_links()}))
EOF
```

Expect 10 links on page 3 (nine plus the email), live text, the right substituted font. Compare the render against `press/KillerOfMen_EPK_<latest>.pdf` page 3 side by side. Luke gives a go or no-go on typeface, line breaks and the mailto link. Any tweak goes into `tools/build-epk-kit.py` or the emitter and the JSON is regenerated; nothing is hand-edited in Canva before the go.

### 6. Full build

In the app: Build all pages (or page by page). The app records each built page in the browser's localStorage and shows an "Export STATE" block; paste that block's values into `STATE.json` (`probes`, `pages_built`, `design.url`).

Check: eleven pages in order; per-page element counts equal `count` in the JSON; pages 3, 5, 8 and 9 screenshotted and compared to the PDF.

### 7. Export and verify

Share › Download › PDF Print, RGB, Flatten OFF, crop marks OFF, all pages. Then:

```bash
venv/bin/python - <<'EOF'
import pymupdf
d = pymupdf.open("/path/to/KillerOfMen_EPK_canva.pdf")
print(len(d), "pages;", [ (round(p.rect.width), round(p.rect.height)) for p in d ][:3])
print(sum(len(p.get_text()) for p in d), "chars;", sum(len(p.get_links()) for p in d), "links")
EOF
```

Expect 11 pages at 1296 × 1728 pt, text on every page, 20 links. Record size and verdicts in `STATE.json`. Put the exported PDF on the Drive under `05 MARKETING / 00 PRESS / EPK BUILDS / CANVA`.

### 8. Optional: real Baskerville (Pro)

```bash
venv/bin/python - <<'EOF'
from fontTools.ttLib import TTCollection
c = TTCollection("/System/Library/Fonts/Supplemental/Baskerville.ttc")
for f in c.fonts:
    style = f["name"].getDebugName(2).replace(" ", "")
    f.save(f"/tmp/Baskerville-{style}.ttf")
EOF
```

Luke uploads Regular, SemiBold and Bold in Canva › Brand › Fonts and swaps the faces in the editor. His call: Apple's licence for uploading a bundled font to a cloud service is unverified. Skip this step if in doubt; Libre Baskerville is right for the film.

### 9. Share

Share › Anyone with the link › Can edit, to the director and producer (they should sign in with free accounts so they can comment and download). A separate view link for press. Record both in `STATE.json`.

## Resuming

1. Read `STATE.json`. `next_step` says where to go; `pages_built` says which pages exist.
2. If the JSON's `source.epk_rev` is older than `press/epk.json`'s `rev`, decide with Luke whether to rebuild (Canva is the master after acceptance; a rebuild discards Canva-side edits on the pages it replaces).
3. The app's localStorage progress lives in the browser that ran it. A different browser starts from `STATE.json` alone: open the existing design by its URL and build only the pages not listed in `pages_built`.
4. The Developer Portal app belongs to the Canva account, not to the machine. Another machine only needs the repo, Node, and Luke logged in.

## Rules that hold here

- Explicit-path commits only; never `git add -A`, stash, `checkout -- .` or `reset --hard` in this checkout: other sessions work in the same tree.
- Before writing any handoff, test that its filename does not exist; a printed warning that does not gate the write is not a check.
- Never modify the masters in `press/assets`; derivatives live under `press/assets/derived/`.
- Every fact on a page comes from `press/epk.json`; write it with `tools/epk.py set`, never by hand and never into code.
- Agents drive Luke's Canva editor at human pace through the documented UI only; Canva's Terms of Use forbid scraping and bypassing access controls.
- Handoffs go in `handoffs/handoff-NNN-epk.md`, mirrored to the Drive `HANDOFFS` folder.
