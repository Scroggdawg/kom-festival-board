### Blue is Claude

Luke asked for a colour that identifies Claude's contributions so changes are trackable. **`#1A5FB4`.** Chosen against the gates rather than by eye, because the `.docx` convention already uses `#C01E1E` for "changed this version" and a colour that collides with it under colour-blindness would quietly break the whole convention:

| | on white | vs the change-red, protan/deutan | vs body ink |
|---|---|---|---|
| **#1A5FB4 blue** | 6.29 : 1 | ΔE 23.0 | ΔE 34.1 |
| teal, rejected | 5.89 : 1 | **ΔE 14.4** | 31.8 |
| green, rejected | 6.54 : 1 | **ΔE 8.0** | 29.8 |

Teal and green both looked fine and both fail. `textutil` shifted the colour during conversion (`1A5FB4` → `1649A5`), so the docx XML is rewritten after conversion and the file now carries exactly the declared hex.

**The convention, written into the document itself:** blue was written by Claude — *including anything read off the poster* — so blue means check it against the source. Black was written by a person. Grey italic means nothing supplied yet.
