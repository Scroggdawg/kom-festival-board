## Where we left off

**This turn (Sep 9, 2026, Opus 5):** Luke asked, plainly, whether this lane can just edit the existing Google Doc. **No — and every route was checked rather than assumed.** `press/epk.json` unchanged at rev 19 · 38 of 47 = 81%.

### Four routes, all closed

| Route | Result |
|---|---|
| Write the file on the mounted Drive | The `.gdoc` is a **175-byte pointer**. Its own contents read *"DO NOT EDIT THIS FILE! ANY CHANGES MADE WILL BE LOST!"* The document lives on Google's servers |
| Google Docs API or a CLI | No `googleapiclient`, no `gdrive`, no `gam`, no `gcloud` on this machine |
| A Docs connector | None installed, and a registry search for google docs / google drive returns **nothing available** |
| **Drive in Luke's real Chrome** | The most promising, and it was tried this turn: `list_connected_browsers` returns `[]`, and the extension reports *"Claude in Chrome is not connected"* |

The Chrome route is the one that would actually work. With the extension installed and signed in, this lane could open the document in his own logged-in session and do the edit directly — that is worth setting up if this keeps coming up.

### The answer that updates *that* document, keeping its URL

The earlier suggestion — open the `.docx` with Google Docs — was subtly wrong for what he asked. **It creates a new document**, with a new URL, losing whatever sharing the existing one has.

**File → Import → Upload → Replace document**, inside the open Doc, replaces the contents of *that* document. Same file, same URL, same sharing, colours intact. That is the precise answer to "update that existing Google Doc", and it is one dialog.

The coloured `.docx` was delivered in chat last turn. The document is at
`https://docs.google.com/document/d/1ae-MPbAq1otTtYA5-SSYYGd13jjvuz1Co2Zi0IrGvSI/edit`.

### Why this keeps recurring

The lane's output is generated from `epk.json` on every change, and the Google Doc is hand-updated. Those two drift the moment anything lands. Until the Chrome extension exists, every data change costs Luke an import. Two ways out, both his call:

- **Install the extension**, and this lane updates the Doc directly.
- **Or let the Doc go**, and treat the published page — [epk.html](https://scroggdawg.github.io/kom-festival-board/epk.html) — as the live copy, since it already updates itself and is reachable from any machine.
