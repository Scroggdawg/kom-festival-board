### The one thing that could go wrong

**If Drive converts the upload to a native Google Sheet, it lands as a `.gsheet` — a 175-byte JSON pointer, not a spreadsheet.** That is the same wall hit earlier with `EPK INFO — all the text.gdoc`, whose own contents read *"DO NOT EDIT THIS FILE! ANY CHANGES MADE WILL BE LOST!"*. A `.gsheet` cannot be read from the filesystem; the data lives on Google's servers.

If that happens the fix is small and it is Luke's to make: in Drive, **File → Download → Microsoft Excel (.xlsx)** into the same folder, or drop the original `.xlsx` in without letting Drive convert it. The watcher looks for `.gsheet` too, so this will be reported rather than silently missed.
