Both sets are DaVinci Resolve gallery exports and keep their gallery names, because `1.1.N` is how the frame is found again in the project. The `.drx` grade sidecars beside the Sep 8 set were left out. The two sets do not overlap, even where the numbers coincide. **One exact duplicate:** `1.1.21` and `1.1.22` in the Sep 8 set are the same frame; both kept, noted.

**Field written:** A.1 Stills, with counts, dimensions, a one-line description of each set, the duplicate, and the five picks still to make.

**Fields deliberately not written:** 2.3 hero still, 4.2 photo behind the statement, 7.2 stills in character, 9.3 still behind the credits. All four were blocked on "master access" and are now choices, not blockers. The PDF builder's holder notes say so. Choosing is Jordan's and Luke's, not mine.

**Inference, not written to a field:** the Dec set is 2048×858, which is 2.39:1, and the Sep set's picture rows give the same ratio. The film's aspect ratio (3.9) is almost certainly 2.39:1, but that field is Yeo's and the stills are grabs, not the master. Worth asking Yeo to confirm with one word instead of a spec sheet.

**Repo weight:** the stills add 247 MB. GitHub's limits are 100 MB per file and about 1 GB per repository, so this is well inside, but a fresh clone is now a quarter gigabyte. If another lane's clone loop starts to hurt, the fix is a web-size JPG set and the PNG masters moved to Drive, not deleting history.
