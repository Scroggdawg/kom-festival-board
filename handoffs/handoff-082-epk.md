### The handoff convention, and the mistake I nearly shipped

Luke asked for a handoff folder on the Drive with a naming convention. My first build was **wrong**: a folder per lane with a private counter per lane. Then I looked at the actual filenames and found **another session is also writing `-epk` handoffs** — 068 through 072, while this session wrote 062 through 067.

So the lane suffix names the *topic*, not the *writer*. Two sessions share the `epk` lane right now. A private per-lane counter would have had them overwriting each other; what has actually kept them apart is that both take the highest number across **all** lanes and add one.

**The rule, now written at `KILLER OF MEN/HANDOFFS/README.txt`:** one counter shared by every lane. Take the highest `NNN` in the folder whoever it belongs to, add one, append your own lane name. Flat folder, not per-lane subfolders, so the counter is one `ls`. All 112 existing handoffs are copied there.

The thirty duplicate numbers already in the repo (030–048, 062–072) are historical, from when lanes kept private counters. **No file was ever overwritten** — the suffix saved them — so nothing is renamed and every `Continues:` link still resolves.
